# 麦思哲（MaiSiZhe）智能Agent校园即时通讯系统 - 数据接口与数据格式设计文档

---

## 1. 接口设计概述

### 1.1 接口规范
- **协议**：HTTP/HTTPS
- **请求格式**：JSON
- **响应格式**：JSON
- **字符编码**：UTF-8
- **认证方式**：JWT Token（Header: `Authorization: Bearer {token}`）

### 1.2 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1704067200000
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | number | 状态码（200成功，其他为错误码） |
| message | string | 响应消息 |
| data | any | 响应数据 |
| timestamp | number | 时间戳 |

### 1.3 错误码定义

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权（Token无效或过期） |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 系统内部错误 |
| 1001 | 用户不存在 |
| 1002 | 密码错误 |
| 1003 | 用户已存在 |
| 2001 | 群组不存在 |
| 2002 | 群成员不存在 |
| 3001 | 消息不存在 |
| 4001 | AI服务调用失败 |

## 2. 用户认证接口

### 2.1 登录接口

**POST** `/api/auth/login`

**请求体**：
```json
{
  "username": "zhangsan",
  "password": "123456"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名（学号/工号） |
| password | string | 是 | 密码 |

**成功响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "userInfo": {
      "id": 1001,
      "username": "zhangsan",
      "realName": "张三",
      "role": 0,
      "classId": "22计科1班",
      "avatar": "https://example.com/avatar.jpg"
    }
  }
}
```

### 2.2 注册接口

**POST** `/api/auth/register`

**请求体**：
```json
{
  "username": "newuser",
  "password": "123456",
  "realName": "新用户",
  "role": 0,
  "classId": "22计科1班"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |
| realName | string | 是 | 真实姓名 |
| role | number | 是 | 角色（0-学生，1-教师，2-管理员） |
| classId | string | 否 | 班级ID（学生必填） |

**成功响应**：
```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "id": 1002,
    "username": "newuser",
    "realName": "新用户"
  }
}
```

## 5. 群组管理接口

### 5.1 创建群组

**POST** `/api/group/create`

**请求体**：
```json
{
  "name": "22计科1班",
  "type": 1,
  "description": "班级群",
  "classCodes": ["22计科1班"],
  "memberIds": [1001, 1002, 1003]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 群名称 |
| type | number | 是 | 群类型（0-普通群，1-班级群，2-课程群） |
| description | string | 否 | 群描述 |
| classCodes | array | 否 | 班号列表（班级群/课程群必填） |
| memberIds | array | 否 | 初始成员列表 |

**成功响应**：
```json
{
  "code": 200,
  "message": "创建成功",
  "data": {
    "id": 10001,
    "name": "22计科1班",
    "type": 1,
    "ownerId": 1001,
```

## 6. 消息接口

### 6.1 发送消息

**POST** `/api/message/send`

**请求体**：
```json
{
  "chatId": "g_10001",
  "content": "大家好",
  "msgType": 0,
  "clientMsgId": "uuid-12345",
  "mentionedUserIds": [1002, 1003]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| chatId | string | 是 | 会话ID（私聊：p_uid1_uid2，群聊：g_gid） |
| content | string | 是 | 消息内容 |
| msgType | number | 是 | 消息类型（0-文本，1-图片，2-文件） |
| clientMsgId | string | 是 | 客户端消息ID（去重用） |
| mentionedUserIds | array | 否 | @提及用户ID列表 |

**成功响应**：
```json
{
  "code": 200,
  "message": "发送成功",
  "data": {
    "id": 1234567890123456789,
    "seqId": 100,
    "chatId": "g_10001",
    "content": "大家好",
    "msgType": 0,
    "createTime": "2024-01-01 10:30:00"
  }
}
```

### 6.2 获取历史消息

**GET** `/api/message/history`

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| chatId | string | 是 | 会话ID |
| lastSeq | number | 是 | 最后一条消息序号 |
| size | number | 否 | 获取数量（默认20） |

**成功响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "messages": [
      {
        "id": 1234567890123456789,
        "chatId": "g_10001",
        "seqId": 99,
        "fromUid": 1001,
        "fromUsername": "zhangsan",
        "fromRealName": "张三",
        "content": "大家好",
        "msgType": 0,
        "createTime": "2024-01-01 10:30:00",
        "isOwn": false
      }
    ],
    "hasMore": true
  }
}
```

### 6.3 消息同步（断线重连）

**GET** `/api/message/sync`

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| chatId | string | 是 | 会话ID |
| lastSeq | number | 是 | 客户端最后收到的消息序号 |

### 6.4 撤回消息

**PUT** `/api/message/revoke`

**请求体**：
```json
{
  "messageId": 1234567890123456789,
  "chatId": "g_10001"
}
```

## 8. WebSocket消息格式

### 8.1 消息结构

```json
{
  "type": "GROUP_CHAT",
  "chatId": "g_10001",
  "clientMsgId": "uuid-12345",
  "content": "大家好",
  "msgType": 0,
  "mentionedUserIds": [1002, 1003],
  "timestamp": 1704067200000
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| type | string | 消息类型（PRIVATE_CHAT/GROUP_CHAT/AI_MESSAGE/SYSTEM） |
| chatId | string | 会话ID |
| clientMsgId | string | 客户端消息ID |
| content | string | 消息内容 |
| msgType | number | 消息类型 |
| mentionedUserIds | array | @提及用户ID列表 |
| timestamp | number | 时间戳 |

### 8.2 心跳消息

**客户端发送**：
```json
{
  "type": "PING",
  "timestamp": 1704067200000
}
```

**服务端响应**：
```json
{
  "type": "PONG",
  "timestamp": 1704067200000
}
```

### 8.3 系统消息

```json
{
  "type": "SYSTEM",
  "event": "MEMBER_JOIN",
  "chatId": "g_10001",
  "data": {
    "userId": 1004,
    "username": "wangwu",
    "joinTime": "2024-01-01 10:30"
  }
}
```

## 9. 数据模型定义

### 9.1 用户模型（User）

```typescript
interface User {
  id: number;
  username: string;
  password: string;
  realName: string;
  role: number;
  classId: string | null;
  avatar: string | null;
  phone: string | null;
  email: string | null;
  status: number;
  createTime: string;
  updateTime: string;
}
```

### 9.2 消息模型（Message）

```typescript
interface Message {
  id: number;
  chatId: string;
  seqId: number;
  fromUid: number;
  fromUsername: string;
  fromRealName: string;
  content: string;
  msgType: number;
  mentionedUserIds: number[];
  fileUrl: string | null;
  fileName: string | null;
  fileSize: number | null;
  isRevoked: boolean;
  createTime: string;
}
```

### 9.3 群组模型（Group）

```typescript
interface Group {
  id: number;
  name: string;
  type: number;
  ownerId: number;
  avatar: string | null;
  description: string | null;
  announcement: string | null;
  maxMembers: number;
  status: number;
  createTime: string;
}
```
