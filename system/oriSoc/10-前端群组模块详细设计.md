## 1. 模块概述

### 1.1 模块定位
群组模块负责群组的创建、管理和群成员管理，是实现群聊功能的核心模块。

### 1.2 核心功能
- 群组创建（普通群、班级群、课程群）
- 群组信息管理（名称、头像、公告）
- 群成员管理（添加、移除、权限设置）
- 群聊消息功能
- 群组搜索与筛选

## 2. 核心组件设计

### 2.1 群组列表组件（GroupList）

#### 2.1.1 功能需求
- 展示用户加入的所有群组
- 显示群头像、名称、成员数量、未读消息数
- 支持搜索过滤
- 支持点击进入群聊

#### 2.1.2 Props设计

| Prop | 类型 | 必填 | 说明 |
|------|------|------|------|
| groups | GroupVO[] | 是 | 群组列表 |
| activeGroupId | number | 否 | 当前活跃群组ID |

#### 2.1.3 Events设计

| Event | 参数 | 说明 |
|-------|------|------|
| select | group: GroupVO | 选中群组 |

#### 2.1.4 组件结构

```vue
<template>
  <div class="group-list">
    <!-- 搜索框 -->
    <div class="search-box">
      <input
        v-model="searchQuery"
        type="text"
        placeholder="搜索群组..."
        class="search-input"
      />
      <Icon name="search" class="search-icon" />
    </div>
    
    <!-- 群组列表 -->
    <div class="groups-wrapper">
      <div
        v-for="group in filteredGroups"
        :key="group.id"
        class="group-item"
        :class="{ active: activeGroupId === group.id }"
        @click="$emit('select', group)"
      >
        <!-- 群头像 -->
        <div class="group-avatar">
          <img v-if="group.avatar" :src="group.avatar" />
          <div v-else class="avatar-placeholder">
            <Icon name="users" />
          </div>
        </div>
        
        <!-- 群信息 -->
        <div class="group-info">
          <div class="group-header">
            <span class="group-name">{{ group.name }}</span>
            <span class="group-type">{{ getGroupTypeName(group.type) }}</span>
          </div>
          <div class="group-footer">
            <span class="member-count">{{ group.memberCount }} 名成员</span>
            <span v-if="group.unreadCount > 0" class="unread-badge">
              {{ group.unreadCount }}
            </span>
          </div>
        </div>
      </div>
    </div>
    
    <!-- 空状态 -->
    <div v-if="filteredGroups.length === 0" class="empty-state">
      <Icon name="users" />
      <span>暂无群组</span>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue';
import { Icon } from '@/components';
import type { GroupVO } from '@/types';

const props = defineProps<{
  groups: GroupVO[];
  activeGroupId?: number;
}>();

defineEmits<{
  select: [group: GroupVO];
}>();

const searchQuery = ref('');

const filteredGroups = computed(() => {
  if (!searchQuery.value) return props.groups;
  
  const query = searchQuery.value.toLowerCase();
  return props.groups.filter(g => 
    g.name.toLowerCase().includes(query)
  );
});

function getGroupTypeName(type: number): string {
  switch (type) {
    case 0: return '普通群';
    case 1: return '班级群';
    case 2: return '课程群';
    default: return '未知';
  }
}
</script>
```

### 2.2 群组详情组件（GroupDetail）

#### 2.2.1 功能需求

#### 2.2.3 Events设计

| Event | 参数 | 说明 |

| setAdmin | userId: number | 设置管理员 |

#### 2.2.4 组件结构

```vue
<template>
  <div class="group-detail">
    <!-- 群头像和名称 -->
    <div class="group-header">
      <div class="group-avatar-large">
        <img v-if="group.avatar" :src="group.avatar" />
        <div v-else class="avatar-placeholder">
          <Icon name="users" />
        </div>
      </div>
      <div class="group-name-wrapper">
        <span class="group-name">{{ group.name }}</span>
        <span class="group-type">{{ getGroupTypeName(group.type) }}</span>
      </div>
      <button 
        v-if="isOwner" 
        class="edit-btn"
        @click="showEditModal = true"
      >
        <Icon name="edit" />
      </button>
    </div>
    
    <!-- 群公告 -->
    <div class="group-announcement">
      <div class="announcement-header">
        <Icon name="bullhorn" />
        <span>群公告</span>
      </div>
      <p>{{ group.announcement || '暂无公告' }}</p>
    </div>
    
    <!-- 群成员列表 -->
    <div class="members-section">
      <div class="section-header">
        <span>群成员 ({{ members.length }})</span>
        <button 
          v-if="isAdmin" 
          class="add-btn"
          @click="showAddMemberModal = true"
        >
          <Icon name="user-plus" />
          添加成员
        </button>
      </div>
      
      <div class="members-list">
        <div
          v-for="member in members"
          :key="member.userId"
          class="member-item"
        >
          <div class="member-avatar">
            <img :src="member.avatar" />
          </div>
          <div class="member-info">
            <span class="member-name">{{ member.realName }}</span>
            <span class="member-role">{{ getMemberRoleName(member.role) }}</span>
          </div>
          <div v-if="canManage(member)" class="member-actions">
            <button 
              v-if="member.role !== 2" 
              class="action-btn"
              @click="$emit('setAdmin', member.userId)"
            >
              设置管理员
            </button>
            <button 
              class="action-btn danger"
              @click="$emit('removeMember', member.userId)"
            >
              移出群聊
            </button>
          </div>
        </div>
      </div>
    </div>
    
    <!-- 编辑群信息弹窗 -->
    <GroupEditModal
      v-if="showEditModal"
      :group="group"
      @confirm="handleEditConfirm"
      @cancel="showEditModal = false"
    />
    
    <!-- 添加成员弹窗 -->
    <AddMemberModal
      v-if="showAddMemberModal"
      :group-id="group.id"
      @confirm="handleAddMember"
      @cancel="showAddMemberModal = false"
    />
  </div>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue';
import { Icon } from '@/components';
import GroupEditModal from './GroupEditModal.vue';
import AddMemberModal from './AddMemberModal.vue';
import type { GroupVO, GroupMemberVO } from '@/types';

const props = defineProps<{
  group: GroupVO;
  members: GroupMemberVO[];
  currentUserId: number;
}>();

const emit = defineEmits<{
  update: [group: Partial<GroupVO>];
  addMember: [userIds: number[]];
  removeMember: [userId: number];
  setAdmin: [userId: number];
}>();

const showEditModal = ref(false);
const showAddMemberModal = ref(false);

const isOwner = computed(() => props.group.ownerId === props.currentUserId);
const isAdmin = computed(() => {
  const member = props.members.find(m => m.userId === props.currentUserId);
  return member?.role === 2 || member?.role === 1;
});

function canManage(member: GroupMemberVO): boolean {
  if (!isAdmin.value) return false;
  if (member.userId === props.currentUserId) return false;
  if (member.role === 2) return false; // 不能管理群主
  return true;
}

function getGroupTypeName(type: number): string {
  switch (type) {
    case 0: return '普通群';
    case 1: return '班级群';
    case 2: return '课程群';
    default: return '未知';
  }
}

function getMemberRoleName(role: number): string {
  switch (role) {
    case 0: return '成员';
    case 1: return '管理员';
    case 2: return '群主';
    default: return '成员';
  }
}

function handleEditConfirm(group: Partial<GroupVO>) {
  emit('update', group);
  showEditModal.value = false;
}

function handleAddMember(userIds: number[]) {
  emit('addMember', userIds);
  showAddMemberModal.value = false;
}
</script>
```

### 2.3 创建群组组件（CreateGroup）

#### 2.3.1 功能需求
- 支持创建普通群、班级群、课程群
- 选择初始成员
- 设置群名称和描述

#### 2.3.2 Events设计

| Event | 参数 | 说明 |
|-------|------|------|
| create | group: CreateGroupDTO | 创建群组 |
| cancel | - | 取消创建 |

#### 2.3.3 组件结构

```vue
<template>
  <div class="create-group-modal">
    <div class="modal-header">
      <span class="title">创建群组</span>
      <button class="close-btn" @click="$emit('cancel')">
        <Icon name="x" />
      </button>
    </div>
    
    <div class="modal-body">
      <!-- 群类型选择 -->
      <div class="form-section">
        <label>群类型</label>
        <div class="type-options">
          <button
            v-for="option in typeOptions"
            :key="option.value"
            class="type-option"
            :class="{ active: groupType === option.value }"
            @click="groupType = option.value"
          >
            <Icon :name="option.icon" />
            <span>{{ option.label }}</span>
          </button>
        </div>
      </div>
      
      <!-- 群名称 -->
      <div class="form-section">
        <label>群名称</label>
        <input
          v-model="groupName"
          type="text"
          placeholder="请输入群名称"
          class="form-input"
        />
      </div>
      
      <!-- 群描述 -->
      <div class="form-section">
        <label>群描述</label>
        <textarea
          v-model="groupDescription"
          placeholder="请输入群描述（可选）"
          class="form-textarea"
        />
      </div>
      
      <!-- 班级选择（班级群/课程群） -->
      <div v-if="groupType !== 0" class="form-section">
        <label>选择班级</label>
        <div class="class-options">
          <label
            v-for="cls in availableClasses"
            :key="cls.id"
            class="class-option"
          >
            <input type="checkbox" v-model="selectedClasses" :value="cls.id" />
            <span>{{ cls.name }}</span>
          </label>
        </div>
      </div>
      
      <!-- 初始成员选择 -->
      <div class="form-section">
        <label>初始成员</label>
        <div class="member-selector">
          <div class="selected-members">
            <div
              v-for="member in selectedMembers"
              :key="member.id"
              class="selected-member"
            >
              <img :src="member.avatar" class="mini-avatar" />
              <span>{{ member.realName }}</span>
              <button @click="removeMember(member.id)">
                <Icon name="x" />
              </button>
            </div>
          </div>
          <button 
            v-if="selectedMembers.length < 50"
            class="add-member-btn"
            @click="showMemberSelector = true"
          >
            <Icon name="user-plus" />
            添加成员
          </button>
        </div>
      </div>
    </div>
    
    <div class="modal-footer">
      <button class="cancel-btn" @click="$emit('cancel')">取消</button>
      <button 
        class="confirm-btn"
        :disabled="!groupName.trim()"
        @click="handleCreate"
      >
        创建
      </button>
    </div>
    
    <!-- 成员选择器弹窗 -->
    <MemberSelector
      v-if="showMemberSelector"
      :exclude-ids="selectedMembers.map(m => m.id)"
      @confirm="handleMemberSelect"
      @cancel="showMemberSelector = false"
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue';
import { Icon } from '@/components';
import MemberSelector from './MemberSelector.vue';
import type { UserVO } from '@/types';

defineEmits<{
  create: [group: CreateGroupDTO];
  cancel: [];
}>();

const groupType = ref(0);
const groupName = ref('');
const groupDescription = ref('');
const selectedClasses = ref<string[]>([]);
const selectedMembers = ref<UserVO[]>([]);
const showMemberSelector = ref(false);

const typeOptions = [
  { value: 0, label: '普通群', icon: 'users' },
  { value: 1, label: '班级群', icon: 'school' },
  { value: 2, label: '课程群', icon: 'book-open' },
];

const availableClasses = [
  { id: '22计科1班', name: '22计科1班' },
  { id: '22计科2班', name: '22计科2班' },
  { id: '22软工1班', name: '22软工1班' },
];

function removeMember(userId: number) {
  selectedMembers.value = selectedMembers.value.filter(m => m.id !== userId);
}

function handleMemberSelect(members: UserVO[]) {
  selectedMembers.value = [...selectedMembers.value, ...members];
  showMemberSelector.value = false;
}

function handleCreate() {
  const group: CreateGroupDTO = {
    name: groupName.value,
    type: groupType.value,
    description: groupDescription.value || undefined,
    classCodes: groupType.value !== 0 ? selectedClasses.value : undefined,
    memberIds: selectedMembers.value.map(m => m.id),
  };
  
  emit('create', group);
}
</script>
```

## 3. 状态管理设计

### 3.1 群组状态（groupStore）

```typescript
export const useGroupStore = defineStore('group', {
  state: () => ({
    // 当前活跃群组ID
    activeGroupId: 0,
    
    // 群组列表
    groups: [] as GroupVO[],
    
    // 群成员列表（key为groupId）
    members: {} as Record<number, GroupMemberVO[]>,
    
    // 未读消息计数
    unreadCounts: {} as Record<number, number>,
    
    // 群组排序
    sortOrders: {} as Record<number, number>,
  }),
  
  getters: {
    // 当前活跃群组
    currentGroup: (state) => {
      return state.groups.find(g => g.id === state.activeGroupId);
    },
    
    // 当前群组成员
    currentMembers: (state) => {
      return state.members[state.activeGroupId] || [];
    },
  },
  
  actions: {
    // 设置活跃群组
    setActiveGroup(groupId: number) {
      this.activeGroupId = groupId;
      this.resetUnread(groupId);
    },
    
    // 设置群组列表
    setGroups(groups: GroupVO[]) {
      this.groups = groups;
    },
    
    // 添加群组
    addGroup(group: GroupVO) {
      this.groups.push(group);
    },
    
    // 更新群组信息
    updateGroup(groupId: number, updates: Partial<GroupVO>) {
      const group = this.groups.find(g => g.id === groupId);
      if (group) {
        Object.assign(group, updates);
      }
    },
    
    // 删除群组
    removeGroup(groupId: number) {
      this.groups = this.groups.filter(g => g.id !== groupId);
      delete this.members[groupId];
    },
    
    // 设置群成员列表
    setMembers(groupId: number, members: GroupMemberVO[]) {
      this.members[groupId] = members;
    },
    
    // 添加群成员
    addMember(groupId: number, member: GroupMemberVO) {
      if (!this.members[groupId]) {
        this.members[groupId] = [];
      }
      this.members[groupId].push(member);
    },
    
    // 移除群成员
    removeMember(groupId: number, userId: number) {
      if (this.members[groupId]) {
        this.members[groupId] = this.members[groupId].filter(m => m.userId !== userId);
      }
    },
    
    // 更新成员角色
    updateMemberRole(groupId: number, userId: number, role: number) {
      const member = this.members[groupId]?.find(m => m.userId === userId);
      if (member) {
        member.role = role;
      }
    },
    
    // 更新未读计数
    incrementUnread(groupId: number) {
      this.unreadCounts[groupId] = (this.unreadCounts[groupId] || 0) + 1;
    },
    
    // 重置未读计数
    resetUnread(groupId: number) {
      this.unreadCounts[groupId] = 0;
    },
    
    // 更新群组排序
    updateSortOrder(groupId: number, order: number) {
      this.sortOrders[groupId] = order;
    },
  },
});
```

## 4. 群组创建流程

### 4.1 创建流程

```
选择群类型
      │
      ▼
输入群名称和描述
      │
      ▼
（班级群/课程群）选择班级
      │
      ▼
选择初始成员
      │
      ▼
提交创建请求
      │
      ▼
服务端创建群组
      │
      ▼
返回群组信息
      │
      ▼
加入群聊
```

### 4.2 创建实现

```typescript
async function createGroup(group: CreateGroupDTO) {
  try {
    const response = await api.post('/api/group/create', group);
    
    if (response.code === 200) {
      const groupVO: GroupVO = response.data;
      
      // 更新状态
      groupStore.addGroup(groupVO);
      groupStore.setMembers(groupVO.id, []);
      
      // 跳转到群聊
      router.push(`/chat/group/${groupVO.id}`);
      
      showToast('群组创建成功');
    }
  } catch (error) {
    console.error('创建群组失败:', error);
    showToast('创建群组失败');
  }
}
```
