## 📝 使用手册

### 1. 注册账号

访问 http://localhost:3000/register
- 填写用户名(4-20位)
- 填写密码(6-20位)
- 填写学号和姓名
- 点击注册

### 2. 登录系统

访问 http://localhost:3000/login
- 输入用户名和密码
- 点击登录
- 自动跳转到聊天页面

### 3. 发送消息

- 左侧选择群组
- 底部输入框输入消息
- 按Enter或点击"发送"
- 支持Shift+Enter换行

### 4. @AI功能

在群聊中输入：
```
@AI 帮我总结一下今天的群聊
```

系统会：
1. 立即显示"🤔 AI正在思考中..."
2. 3-10秒后显示AI回复

### 5. 查看历史消息

- 切换群组时自动加载最近50条消息
- 滚动查看历史消息
