## 📝 开发检查清单

### 环境准备
- [ ] JDK 17+ 已安装
- [ ] Maven 3.8+ 已安装
- [ ] Node.js 18+ 已安装
- [ ] MySQL 8.0+ 已安装并启动
- [ ] Redis 7.x 已安装并启动

### 数据库
- [ ] 执行 `code/database/init.sql`
- [ ] 验证11张表已创建
- [ ] 验证测试数据已插入

### 后端
- [ ] 修改 `application.yml` 数据库配置
- [ ] 运行 `mvn spring-boot:run`
- [ ] 访问 `http://localhost:8080`

- [ ] 执行 `npm create vue@latest`
- [ ] 安装依赖 `npm install`
