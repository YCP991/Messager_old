## ❌ 问题3: 数据库表名不匹配

### 错误信息
```
java.sql.SQLSyntaxErrorException: Table 'maisizhe.im_group_member' doesn't exist
SQL: SELECT ... FROM im_group_member WHERE (user_id = ? AND is_quit = ?)
```

### 原因分析
- 数据库中实际的表名是 `group_member`（来自init.sql）
- 但GroupMember实体类中配置的是 `@TableName("im_group_member")`
- MyBatis-Plus根据注解生成SQL时使用了错误的表名

### 解决方案
修改 [GroupMember.java](file://C:/Users/Champion%20Young/Desktop/课设/Messager/code/backend/src/main/java/com/maisizhe/modules/group/entity/GroupMember.java#L16)：

```java
// 修改前
@TableName("im_group_member")

// 修改后
@TableName("group_member")
```

### 验证结果
✅ 后端重启后，表名匹配正确

## ❌ 问题4: WebSocket连接失败

### 错误信息
```
WebSocket connection to 'ws://localhost:8080/ws?token=xxx' failed
WebSocket错误: Event {isTrusted: true, type: 'error', ...}
```

### 原因分析
- **前端**: 使用查询参数方式传递token: `ws://localhost:8080/ws?token=xxx`
- **后端**: 期望路径参数方式: `@ServerEndpoint("/ws/{token}")`
- 两种方式不匹配，导致WebSocket握手失败

### 解决方案
修改前端 [websocket.ts](file://C:/Users/Champion%20Young/Desktop/课设/Messager/code/frontend/src/utils/websocket.ts#L46)：

```typescript
// 修改前
this.ws = new WebSocket(`${this.url}?token=${this.token}`);

// 修改后
this.ws = new WebSocket(`${this.url}/${this.token}`);
```

**说明**: 
- 前端URL现在是: `ws://localhost:8080/ws/eyJhbGci...` (token作为路径的一部分)
- 后端通过 `@PathParam("token")` 接收token

### 验证结果
⏳ 等待前端热更新后测试

## 📝 技术要点总结

### 1. MyBatis-Plus表名映射
```java
@TableName("实际数据库表名")  // 必须与数据库中的表名完全一致
public class Entity {
    // ...
}
```

**常见命名规范**:
- 数据库: `snake_case` (如: `group_member`)
- Java类: `PascalCase` (如: `GroupMember`)
- 通过 `@TableName` 明确指定映射关系

### 2. WebSocket token传递方式

**方式1: 路径参数** (当前使用)
```
前端: ws://localhost:8080/ws/{token}
后端: @ServerEndpoint("/ws/{token}")
      @PathParam("token") String token
```

**方式2: 查询参数**
```
前端: ws://localhost:8080/ws?token={token}
后端: @ServerEndpoint("/ws")
      Session.getUserProperties().get("token")
```

**方式3: 子协议**
```
前端: new WebSocket(url, ['Bearer', token])
后端: session.getNegotiatedSubprotocol()
```

推荐使用**方式1**（路径参数），简单直接。

### 3. MyBatis-Plus自动填充

**步骤**:
1. 在实体字段上添加注解:
   ```java
   @TableField(fill = FieldFill.INSERT)
   private LocalDateTime createTime;
   
   @TableField(fill = FieldFill.INSERT_UPDATE)
   private LocalDateTime updateTime;
   ```

2. 创建MetaObjectHandler实现类:
   ```java
   @Component
   public class MyMetaObjectHandler implements MetaObjectHandler {
       @Override
       public void insertFill(MetaObject metaObject) {
           this.strictInsertFill(metaObject, "createTime", LocalDateTime.class, LocalDateTime.now());
           this.strictInsertFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
       }
       
       @Override
       public void updateFill(MetaObject metaObject) {
           this.strictUpdateFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
       }
   }
   ```

- 但WebSocket连接等全局状态可能需要重新登录
- Spring Boot后端修改Java代码需要重启应用

### 3. Token有效期
- JWT Token有效期: 24小时
- 如果Token过期，需要重新登录
- WebSocket连接也会断开
