## ❌ 问题1: CORS配置错误

### 错误信息
```
java.lang.IllegalArgumentException: When allowCredentials is true, allowedOrigins cannot contain 
the special value "*" since that cannot be set on the "Access-Control-Allow-Origin" response header. 
To allow credentials to a set of origins, list them explicitly or consider using "allowedOriginPatterns" instead.
```

### 原因分析
Spring Security 6中，当设置 `allowCredentials=true` 时，不能使用 `allowedOrigins=["*"]`，必须使用 `allowedOriginPatterns`。

### 解决方案
修改 [SecurityConfig.java](file://C:/Users/Champion%20Young/Desktop/课设/Messager/code/backend/src/main/java/com/maisizhe/config/SecurityConfig.java#L94)：

```java
// 修改前
configuration.setAllowedOrigins(Arrays.asList("*"));

// 修改后
configuration.setAllowedOriginPatterns(Arrays.asList("*"));
```

### 验证结果
✅ 后端重启后，CORS错误消失

## ❌ 问题2: Vue inject() 警告和响应拦截器错误

### 错误信息
```
[Vue warn]: inject() can only be used inside setup() or functional components.
注册失败: TypeError: Cannot read properties of undefined (reading 'error')
```

### 原因分析
在axios响应拦截器中使用了 `useMessage()` from naive-ui，但这是一个Vue Composition API的hook，只能在组件的 `setup()` 或 `<script setup>` 中使用，不能在普通的TypeScript文件中使用。

### 解决方案
修改 [request.ts](file://C:/Users/Champion%20Young/Desktop/课设/Messager/code/frontend/src/utils/request.ts)：

**修改前**:
```typescript
import { useMessage } from 'naive-ui';

// 在响应拦截器中
const messageApi = useMessage();
messageApi.error(message || '请求失败');
```

**修改后**:
```typescript
// 移除 useMessage 导入
// 使用 console.error 代替
console.error('API错误:', message || '请求失败');
```

### 更好的解决方案（可选）
如果需要在拦截器中显示UI提示，可以：
1. 创建一个全局的消息服务
2. 在main.ts中初始化
3. 在拦截器中调用该服务

示例：
```typescript
// utils/message.ts
import { createDiscreteApi } from 'naive-ui';

const { message } = createDiscreteApi(['message']);

export function showError(msg: string) {
  message.error(msg);
}

// request.ts
import { showError } from '@/utils/message';
showError(message || '请求失败');
```

### 验证结果
✅ 前端热更新后，inject警告消失
