## 💡 关键技术方案

### 1. 消息双轴定序

**问题**: 如何保证消息的全局唯一性和会话内顺序性？

**解决方案**:
- **全局ID**: Snowflake算法生成的`id`字段
- **会话内序列号**: Redis INCR生成的`seq_id`字段

```java
// 生成chat_id
String chatId = "g_" + groupId; // 群聊
String chatId = "p_" + smallId + "_" + largeId; // 私聊

// Redis原子自增seq_id
Long seqId = redisUtil.incr("seq:chat:" + chatId);
```

**优势**:
- ✅ 保证消息全局唯一性
- ✅ 保证会话内消息顺序性
- ✅ 高性能(原子操作无锁竞争)

### 3. AI异步削峰

**问题**: LLM响应慢(3-10秒)，同步调用会阻塞线程池

**解决方案**: 独立线程池 + BlockingQueue

```java
@Bean(name = "aiTaskExecutor")
public Executor aiTaskExecutor() {
    ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
    executor.setCorePoolSize(4);
    executor.setMaxPoolSize(8);
    executor.setQueueCapacity(500);
    return executor;
}

// 异步执行
aiTaskExecutor.execute(() -> {
    String response = aiService.chat(message);
    sendAiResponse(groupId, response);
});
```

**工作流程**:
1. 用户发送 `@AI 帮我总结`
2. 立即返回占位消息("🤔 AI正在思考中...")
3. 任务入队到BlockingQueue
4. AI Worker线程池异步消费
5. 通过标准消息通道推送结果

---

### 4. 前端WebSocket自动重连

**问题**: 网络不稳定导致WebSocket断线

**解决方案**: 指数退避重连算法

```typescript
private attemptReconnect(): void {
  const delay = this.reconnectDelay * Math.pow(2, this.reconnectCount);
  // 3s → 6s → 12s → 24s → 48s
  
  this.reconnectTimer = window.setTimeout(() => {
    this.reconnectCount++;
    this.connect();
  }, delay);
}
```

**优势**:
- ✅ 避免频繁重连导致服务器压力
- ✅ 网络恢复后快速重连
- ✅ 最大重连次数限制(10次)
