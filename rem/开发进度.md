## 📝 开发笔记

### 关键技术点
1. **消息双轴定序**: Snowflake ID + Redis INCR seq_id
2. **WebSocket集群**: Redis Stream消息总线
3. **AI削峰**: 独立线程池 + BlockingQueue
4. **权限控制**: AOP切面 + 自定义注解

### 常见问题
- Q: 为什么不按月分表?
- A: 校园规模下单表完全够用,跨月查询复杂度高

- Q: WebSocket如何保证消息不丢失?
- A: Redis持久化 + 客户端seq_id补盲机制
