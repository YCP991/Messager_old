# 麦思哲（MaiSiZhe）后端详细设计方案

## 1. 项目概述

### 1.1 项目名称
麦思哲(MaiSiZhe) - 智能Agent校园即时通讯系统后端

### 1.2 技术栈选型
- **核心框架**: Spring Boot 3.2+
- **语言**: Java 17+
- **安全框架**: Spring Security + JWT
- **持久层**: MyBatis-Plus 3.5+
- **数据库**: MySQL 8.0
- **缓存**: Redis 7.x (Jedis/Lettuce)
- **WebSocket**: Spring WebSocket (原生Handler)
- **消息队列**: Redis Stream
- **AI接口**: DeepSeek/Qwen API
- **文件存储**: 本地存储/阿里云OSS
- **工具库**: Hutool, Lombok, Jackson

### 1.3 设计目标
- 实现高可用长连接网关(支持5000+并发连接)
- 保证消息"不丢、不乱、不重"(ACK机制、双轴定序)
- AI异步削峰处理(独立线程池、阻塞队列)
- 模块化单体架构(DDD-lite,便于后续微服务拆分)
- 完善的权限体系(RBAC + 资源权限 + 群身份)

#### 3.1.1 WebSocket握手拦截器

```java
// websocket/interceptor/WebSocketHandshakeInterceptor.java

@Component
public class WebSocketHandshakeInterceptor implements HandshakeInterceptor {
    
    @Autowired
    private JwtUtil jwtUtil;
    
    @Override
    public boolean beforeHandshake(ServerHttpRequest request, 
                                   ServerHttpResponse response,
                                   WebSocketHandler wsHandler,
                                   Map<String, Object> attributes) throws Exception {
        
        // 从URL参数获取token
        String token = request.getURI().getQuery();
        if (token == null || !token.startsWith("token=")) {
            return false;
        }
        
        token = token.substring(6);
        
        // 验证JWT
        if (!jwtUtil.validateToken(token)) {
            return false;
        }
        
        // 解析用户信息
        Long userId = jwtUtil.getUserIdFromToken(token);
        attributes.put("userId", userId);
        
        return true;
    }
}
```

#### 3.1.2 用户会话管理器

```java
// websocket/session/UserSessionManager.java

@Component
public class UserSessionManager {
    
    // 用户ID -> WebSocket Session
    private final ConcurrentHashMap<Long, WebSocketSession> sessionMap = new ConcurrentHashMap<>();
    
    /**
     * 添加用户会话
     */
    public void addSession(Long userId, WebSocketSession session) {
        sessionMap.put(userId, session);
        
        // 更新Redis在线状态
        RedisUtil.setEx(RedisKeyConstants.ONLINE_USER + userId, "1", 60);
    }
    
    /**
     * 移除用户会话
     */
    public void removeSession(Long userId) {
        sessionMap.remove(userId);
        
        // 删除Redis在线状态
        RedisUtil.delete(RedisKeyConstants.ONLINE_USER + userId);
    }
    
    /**
     * 获取用户会话
     */
    public WebSocketSession getSession(Long userId) {
        return sessionMap.get(userId);
    }
    
    /**
     * 检查用户是否在线
     */
    public boolean isOnline(Long userId) {
        return sessionMap.containsKey(userId);
    }
    
    /**
     * 向指定用户发送消息
     */
    public void sendMessageToUser(Long userId, TextMessage message) {
        WebSocketSession session = sessionMap.get(userId);
        if (session != null && session.isOpen()) {
            try {
                session.sendMessage(message);
            } catch (IOException e) {
                log.error("发送消息失败: userId={}", userId, e);
                removeSession(userId);
            }
        }
    }
}
```

#### 3.1.3 WebSocket处理器

```java
// websocket/handler/ChatWebSocketHandler.java

@Component
public class ChatWebSocketHandler extends TextWebSocketHandler {
    
    @Autowired
    private UserSessionManager sessionManager;
    
    @Autowired
    private MessageDispatcher messageDispatcher;
    
    @Override
    public void afterConnectionEstablished(WebSocketSession session) throws Exception {
        Long userId = (Long) session.getAttributes().get("userId");
        sessionManager.addSession(userId, session);
        
        // 广播用户上线
        broadcastUserOnline(userId);
        
        log.info("用户建立WebSocket连接: userId={}", userId);
    }
    
    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) throws Exception {
        Long userId = (Long) session.getAttributes().get("userId");
        
        // 解析消息
        WSMessage wsMessage = JSON.parseObject(message.getPayload(), WSMessage.class);
        
        // 处理心跳
        if ("PING".equals(wsMessage.getType())) {
            session.sendMessage(new TextMessage("{\"type\":\"PONG\"}"));
            return;
        }
        
        // 分发消息
        messageDispatcher.dispatch(userId, wsMessage);
    }
    
    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) throws Exception {
        Long userId = (Long) session.getAttributes().get("userId");
        sessionManager.removeSession(userId);
        
        // 广播用户下线
        broadcastUserOffline(userId);
        
        log.info("用户断开WebSocket连接: userId={}", userId);
    }
    
    @Override
    public void handleTransportError(WebSocketSession session, Throwable exception) throws Exception {
        Long userId = (Long) session.getAttributes().get("userId");
        sessionManager.removeSession(userId);
        log.error("WebSocket传输错误: userId={}", userId, exception);
    }
}
```

#### 3.2.1 消息分发器

```java
// websocket/dispatcher/MessageDispatcher.java

@Component
public class MessageDispatcher {
    
    @Autowired
    private MessageService messageService;
    
    @Autowired
    private RedisUtil redisUtil;
    
    /**
     * 分发消息
     */
    public void dispatch(Long fromUserId, WSMessage message) {
        String type = message.getType();
        
        switch (type) {
            case "PRIVATE_MESSAGE":
                handlePrivateMessage(fromUserId, message.getData());
                break;
            case "GROUP_MESSAGE":
                handleGroupMessage(fromUserId, message.getData());
                break;
            default:
                log.warn("未知消息类型: {}", type);
        }
    }
    
    /**
     * 处理私聊消息
     */
    private void handlePrivateMessage(Long fromUserId, JSONObject data) {
        Long toUserId = data.getLong("toUserId");
        String content = data.getString("content");
        String clientMsgId = data.getString("clientMsgId");
        
        // 去重检查
        if (isDuplicate(clientMsgId)) {
            log.warn("重复消息: clientMsgId={}", clientMsgId);
            return;
        }
        
        // 构建消息对象
        Message msg = buildMessage(fromUserId, toUserId, content, clientMsgId);
        
        // 发送消息
        messageService.sendPrivateMessage(msg);
    }
    
    /**
     * 处理群聊消息
     */
    private void handleGroupMessage(Long fromUserId, JSONObject data) {
        Long groupId = data.getLong("groupId");
        String content = data.getString("content");
        String clientMsgId = data.getString("clientMsgId");
        
        // 去重检查
        if (isDuplicate(clientMsgId)) {
            log.warn("重复消息: clientMsgId={}", clientMsgId);
            return;
        }
        
        // 构建消息对象
        Message msg = buildMessage(fromUserId, groupId, content, clientMsgId);
        
        // 发送消息
        messageService.sendGroupMessage(msg);
    }
    
    /**
     * 检查消息是否重复
     */
    private boolean isDuplicate(String clientMsgId) {
        String key = RedisKeyConstants.CLIENT_MSG_ID + clientMsgId;
        Boolean exists = redisUtil.hasKey(key);
        if (Boolean.TRUE.equals(exists)) {
            return true;
        }
        
        // 设置5分钟过期
        redisUtil.setEx(key, "1", 300);
        return false;
    }
}
```

#### 3.2.2 消息服务实现

```java
// modules/message/service/impl/MessageServiceImpl.java

@Service
public class MessageServiceImpl implements MessageService {
    
    @Autowired
    private MessageMapper messageMapper;
    
    @Autowired
    private RedisUtil redisUtil;
    
    @Autowired
    private UserSessionManager sessionManager;
    
    @Autowired
    private RedisStreamListener redisStreamListener;
    
    @Autowired
    private MentionParser mentionParser;
    
    /**
     * 发送私聊消息
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public void sendPrivateMessage(Message message) {
        // 1. 生成chat_id
        String chatId = generatePrivateChatId(message.getFromUid(), message.getToUid());
        message.setChatId(chatId);
        
        // 2. 双轴定序
        Long seqId = generateSeqId(chatId);
        message.setSeqId(seqId);
        
        // 3. 写入MySQL
        messageMapper.insert(message);
        
        // 4. 写入Redis ZSet缓存
        cacheMessage(chatId, message);
        
        // 5. 发布到Redis Stream
        publishToRedisStream(message);
        
        // 6. 发布事件(用于关键词提醒等)
        publishMessageSavedEvent(message);
    }
    
    /**
     * 发送群聊消息
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public void sendGroupMessage(Message message) {
        // 1. 生成chat_id
        String chatId = "g_" + message.getGroupId();
        message.setChatId(chatId);
        
        // 2. 双轴定序
        Long seqId = generateSeqId(chatId);
        message.setSeqId(seqId);
        
        // 3. 解析@提及
        List<Long> mentionedUsers = mentionParser.parseMentions(message.getContent());
        message.setMentionedUsers(JSON.toJSONString(mentionedUsers));
        
        // 4. 写入MySQL
        messageMapper.insert(message);
        
        // 5. 写入Redis ZSet缓存
        cacheMessage(chatId, message);
        
        // 6. 发布到Redis Stream
        publishToRedisStream(message);
        
        // 7. 检测是否@AI
        if (mentionParser.isAtAI(message.getContent())) {
            triggerAIWorkflow(message);
        }
        
        // 8. 发布事件
        publishMessageSavedEvent(message);
    }
    
    /**
     * 生成序列号(Redis INCR)
     */
    private Long generateSeqId(String chatId) {
        String key = RedisKeyConstants.SEQ_ID_PREFIX + chatId;
        return redisUtil.incr(key);
    }
    
    /**
     * 缓存消息到Redis ZSet
     */
    private void cacheMessage(String chatId, Message message) {
        String key = RedisKeyConstants.CHAT_MSG_PREFIX + chatId;
        
        // 添加到ZSet,score为seqId
        redisUtil.zAdd(key, message.getSeqId(), JSON.toJSONString(message));
        
        // 只保留最近100条
        redisUtil.zRemoveRange(key, 0, -101);
    }
    
    /**
     * 发布到Redis Stream
     */
    private void publishToRedisStream(Message message) {
        redisStreamListener.publishMessage(message);
    }
}
```

#### 3.3.2 AI工作流

```java
// modules/ai/workflow/AtAIWorkflow.java

@Component
public class AtAIWorkflow {
    
    @Autowired
    private AIService aiService;
    
    @Autowired
    private MessageService messageService;
    
    @Autowired
    private ConversationMemory conversationMemory;
    
    /**
     * 触发@AI工作流
     */
    @Async("aiTaskExecutor")
    public void execute(Message triggerMessage) {
        Long groupId = triggerMessage.getGroupId();
        Long fromUserId = triggerMessage.getFromUid();
        String question = extractQuestion(triggerMessage.getContent());
        
        try {
            // 1. 立即发送占位消息
            Message placeholderMsg = createPlaceholderMessage(groupId);
            messageService.sendSystemMessage(placeholderMsg);
            
            // 2. 提取会话上下文
            List<Message> context = conversationMemory.getContext(groupId, 5);
            
            // 3. 构建Prompt
            String prompt = PromptBuilder.buildGroupPrompt(question, context);
            
            // 4. 调用大模型
            String answer = aiService.callLLM(prompt);
            
            // 5. 发送AI回复
            Message aiResponse = createAIResponse(groupId, answer, placeholderMsg.getId());
            messageService.sendGroupMessage(aiResponse);
            
        } catch (Exception e) {
            log.error("AI工作流执行失败", e);
            // 发送失败提示
```

### 3.5 权限切面设计

```java
// security/permission/GroupPermissionAspect.java

@Aspect
@Component
public class GroupPermissionAspect {
    
    @Before("@annotation(groupPermission)")
    public void checkPermission(JoinPoint joinPoint, GroupPermission groupPermission) {
        // 1. 获取当前用户ID
        Long userId = UserContextHolder.getUserId();
        
        // 2. 获取方法参数中的groupId
        Long groupId = extractGroupId(joinPoint);
        
        // 3. 查询群组类型
        GroupInfo group = groupMapper.selectById(groupId);
        if (group == null) {
            throw new BusinessException("群组不存在");
        }
        
        // 4. 查询用户在群内的角色
        GroupMember member = groupMemberMapper.selectOne(
            new LambdaQueryWrapper<GroupMember>()
                .eq(GroupMember::getGroupId, groupId)
                .eq(GroupMember::getUserId, userId)
        );
        
        // 5. 校验群类型权限
        GroupTypeEnum[] allowTypes = groupPermission.allowGroupTypes();
        if (allowTypes.length > 0) {
            boolean allowed = Arrays.stream(allowTypes)
                .anyMatch(t -> t.getCode() == group.getType());
            if (!allowed) {
                throw new GroupPermissionException("无权操作该类型的群组");
            }
        }
        
        // 6. 校验群内角色权限
        if (member == null) {
            throw new GroupPermissionException("不是群组成员");
        }
        
        MemberRoleEnum[] requiredRoles = groupPermission.requiredRoles();
        boolean hasRequiredRole = Arrays.stream(requiredRoles)
            .anyMatch(r -> r.getCode() == member.getRole());
        
        if (!hasRequiredRole) {
            throw new GroupPermissionException("权限不足");
        }
    }
}
```

```java
/**
 * 缓存最近100条消息到Redis ZSet
 */
public void cacheMessage(String chatId, Message message) {
    String key = RedisKeyConstants.CHAT_MSG_PREFIX + chatId;
    
    // score使用seqId,value为消息JSON
    redisUtil.zAdd(key, message.getSeqId(), JSON.toJSONString(message));
    
    // 只保留最近100条
    redisUtil.zRemoveRange(key, 0, -101);
    
    // 设置过期时间(24小时)
    redisUtil.expire(key, 86400);
}

/**
 * 从缓存获取增量消息
 */
public List<Message> getMissedMessages(String chatId, Long lastSeq) {
    String key = RedisKeyConstants.CHAT_MSG_PREFIX + chatId;
    
    // 获取score > lastSeq的所有消息
    Set<String> messages = redisUtil.zRangeByScore(key, lastSeq + 1, Double.MAX_VALUE);
    
    return messages.stream()
        .map(json -> JSON.parseObject(json, Message.class))
        .sorted(Comparator.comparing(Message::getSeqId))
        .collect(Collectors.toList());
}
```

## 12. 总结

本后端设计方案采用模块化单体架构,通过以下核心技术实现了高性能、高可用的校园IM系统:

1. **WebSocket长连接网关**: 原生Handler + Redis Stream实现分布式消息路由
2. **消息可靠性保障**: 双轴定序(Snowflake + Redis INCR)、去重、ACK机制
3. **AI异步削峰**: 独立线程池 + 阻塞队列,避免大模型调用阻塞主线程
4. **策略模式解耦**: 群组创建逻辑通过策略模式优雅扩展
5. **三维权限体系**: RBAC + 资源权限 + 群身份,AOP统一校验
6. **缓存分层设计**: Redis ZSet缓存热消息,MySQL持久化,读写分离
7. **事件驱动架构**: Spring Event解耦业务逻辑,便于扩展

该方案充分考虑了工程实践中的痛点问题(消息顺序性、AI高延迟、集群扩展),是一个可落地、可扩展的后端解决方案。
