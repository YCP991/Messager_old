## ⚠️ 注意事项

### 1. 数据库配置
确保MySQL已启动,并修改`application.yml`中的用户名密码:
```yaml
spring:
  datasource:
    username: your_username
    password: your_password
```

### 2. Redis配置
确保Redis已启动:
```bash
# Windows
redis-server

# Linux/Mac
sudo systemctl start redis
```

### 3. 端口占用
- 后端: 8080
- 前端: 3000
- MySQL: 3306
- Redis: 6379

如有冲突,请修改配置文件。
