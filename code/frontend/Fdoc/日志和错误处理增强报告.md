## ✅ 已完成增强

### 1. HTTP请求工具增强 ✨ 修改

**文件**: `utils/request.ts`

**新增功能**:

#### 请求日志增强
- 为每个请求生成唯一请求ID
- 记录请求方法、URL、参数、数据
- 记录响应状态、耗时
- 区分正常响应和异常响应的日志级别

**日志格式**:
```
[abc12345] >>> GET /friend/list | params: {"keyword":"张三"}
[abc12345] <<< 200 (0) | 45ms
[abc12345] <<< VALIDATION_ERROR (400) | 12ms | 参数校验失败
```

#### 错误分类系统
新增错误类型枚举：
```typescript
enum ErrorType {
  NETWORK_ERROR,      // 网络连接失败
  TIMEOUT_ERROR,      // 请求超时
  AUTH_ERROR,         // 认证失败（401）
  PERMISSION_ERROR,   // 权限不足（403）
  NOT_FOUND_ERROR,    // 资源不存在（404）
  SERVER_ERROR,       // 服务器错误（500）
  VALIDATION_ERROR,   // 参数校验失败（400）
  BUSINESS_ERROR,     // 业务逻辑错误
  UNKNOWN_ERROR       // 未知错误
}
```

#### 错误信息增强
返回格式化的错误信息：
```typescript
interface ErrorInfo {
  type: ErrorType;       // 错误类型
  code: number;          // 错误码
  message: string;       // 错误消息
  requestId?: string;    // 请求ID
  details?: any;         // 详细信息
}
```

#### 特殊处理
- 401错误自动跳转登录页
- 清除本地存储的token和用户信息
- 网络错误提供友好提示
- 超时错误自动识别

### 2. 日志管理工具 ✨ 新增

**文件**: `utils/logger.ts`

**功能**:
- 提供统一的日志输出接口
- 支持多级别日志（DEBUG/INFO/WARN/ERROR）
- 支持时间戳和颜色标记
- 生产环境自动关闭DEBUG日志
- 支持分组、表格、性能计时等高级功能

**使用示例**:
```typescript
import logger from '@/utils/logger';

// 基础日志
logger.debug('调试信息', data);
logger.info('正常信息', data);
logger.warn('警告信息', data);
logger.error('错误信息', error);

// 分组日志
logger.group('用户操作');
logger.info('点击按钮');
logger.info('发送请求');
logger.groupEnd();

// 性能计时
logger.time('API请求');
await fetchAPI();
logger.timeEnd('API请求');

// 表格日志
logger.table(users);
```

**日志输出示例**:
```
[Messager | 14:30:25.123 | INFO] WebSocket连接成功 (45ms)
[Messager | 14:30:25.456 | WARN] 参数校验失败: groupName不能为空
[Messager | 14:30:25.789 | ERROR] 网络连接失败，请检查网络
```

## 🔍 日志查看方式

### 浏览器控制台
打开浏览器开发者工具（F12），查看Console标签。

### 日志过滤
Chrome控制台支持日志过滤：
- 输入 `Messager` 只显示应用日志
- 输入 `ERROR` 只显示错误日志
- 输入 `WebSocket` 只显示WebSocket相关日志

### 日志级别控制
```typescript
// 开发环境显示所有日志
logger.setLevel(LogLevel.DEBUG);

// 生产环境只显示INFO及以上
logger.setLevel(LogLevel.INFO);

// 关闭所有日志
logger.setLevel(LogLevel.NONE);
```

## 📝 最佳实践

### 1. 组件中使用logger
```typescript
import logger from '@/utils/logger';

export default {
  mounted() {
    logger.info('组件挂载', { componentName: 'Chat' });
  },
  methods: {
    async fetchData() {
      logger.time('获取数据');
      try {
        const data = await api.getData();
        logger.info('数据获取成功', { count: data.length });
      } catch (error) {
        logger.error('数据获取失败', error);
      }
      logger.timeEnd('获取数据');
    }
  }
}
```

### 2. API调用错误处理
```typescript
import { ErrorType } from '@/utils/request';

async function handleApiCall() {
  try {
    const result = await api.getData();
    // 处理成功结果
  } catch (error) {
    if (error.type === ErrorType.NETWORK_ERROR) {
      message.error('网络连接失败，请检查网络');
    } else if (error.type === ErrorType.AUTH_ERROR) {
      // 自动跳转登录页，无需额外处理
    } else {
      message.error(error.message);
    }
    logger.error('API调用失败', error);
  }
}
```

### 3. WebSocket连接管理
```typescript
ws.onConnected(() => {
  logger.info('WebSocket已连接');
  // 开始发送消息
});

ws.onDisconnected(() => {
  logger.warn('WebSocket已断开');
  // 显示离线提示
});

ws.onError((error) => {
  logger.error('WebSocket错误', error);
  // 显示错误提示
});
```
