## 📝 注意事项

1. **后端依赖**：确保 Redis 服务已启动，因为好友模块依赖 Redis 查询用户在线状态
2. **数据库**：确保 `friend` 表已存在（运行 `init.sql` 初始化脚本）
3. **前端**：运行 `npm install` 安装新增的依赖（如果有）
4. **跨域**：确保后端 CORS 配置正确，允许前端访问
