# 麦思哲(MaiSiZhe)后端测试文档

## 1. 测试概述

本测试文档描述了麦思哲后端系统的单元测试和集成测试策略、测试范围及执行方法。

### 1.1 测试框架
- **JUnit 5**: 核心测试框架
- **Mockito**: Mock对象框架，用于单元测试
- **Spring Boot Test**: Spring Boot集成测试支持
- **MockMvc**: HTTP接口测试

### 1.2 测试类型
| 类型 | 说明 | 文件命名规范 |
|------|------|-------------|
| 单元测试 | 测试单个类或方法，使用Mock隔离依赖 | `*Test.java` |
| 集成测试 | 测试多个组件协作，使用真实Spring上下文 | `*IntegrationTest.java` |

## 3. 测试执行方法

### 3.1 执行所有测试
```bash
mvn test
```

### 3.2 执行指定模块测试
```bash
# 用户认证模块
mvn test -Dtest="com.maisizhe.modules.user.*"

# 群组管理模块
mvn test -Dtest="com.maisizhe.modules.group.*"

# 消息系统模块
mvn test -Dtest="com.maisizhe.modules.message.*"

# WebSocket模块
mvn test -Dtest="com.maisizhe.websocket.*"
```

### 3.3 执行单个测试类
```bash
mvn test -Dtest="UserServiceTest"
```

### 3.4 执行单个测试方法
```bash
mvn test -Dtest="UserServiceTest#testLoginSuccess"
```

### 3.5 生成测试报告
```bash
mvn test jacoco:report
```

## 5. 测试最佳实践

### 5.1 单元测试原则
1. **独立性**: 每个测试方法独立，不依赖其他测试
2. **可重复性**: 测试结果稳定，多次执行结果一致
3. **Mock隔离**: 使用Mockito隔离外部依赖
4. **命名规范**: 使用`@DisplayName`描述测试意图

### 5.2 集成测试原则
1. **真实上下文**: 使用`@SpringBootTest`加载完整Spring上下文
2. **事务管理**: 测试后自动回滚，避免污染数据库
3. **端口配置**: 使用随机端口避免冲突

### 5.3 测试覆盖率目标
| 模块 | 目标覆盖率 |
|------|----------|
| 核心业务逻辑 | ≥ 80% |
| Controller层 | ≥ 70% |
| 工具类 | ≥ 90% |

## 6. 测试报告解读

### 6.1 测试结果状态
- ✅ **SUCCESS**: 测试通过
- ❌ **FAILURE**: 测试失败（断言不满足）
- ⚠️ **ERROR**: 测试错误（异常导致）

### 6.2 常见问题排查
| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 测试失败 | Mock配置错误 | 检查when/thenReturn配置 |
| 测试错误 | 依赖注入失败 | 检查@InjectMocks/@Mock配置 |
| 数据库连接失败 | 配置错误 | 检查application-test.yml |

## 7. 附录

### 7.1 测试依赖配置
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-test</artifactId>
    <scope>test</scope>
</dependency>
```

### 7.2 测试类模板

**单元测试模板**:
```java
@ExtendWith(MockitoExtension.class)
class XxxServiceTest {
    @Mock
    private XxxMapper mapper;
    
    @InjectMocks
    private XxxServiceImpl service;
    
    @Test
    @DisplayName("测试描述")
    void testXxx() {
        // Mock行为
        when(mapper.selectById(1L)).thenReturn(mockData);
        
        // 执行测试
        XxxVO result = service.getXxx(1L);
        
        // 验证结果
        assertNotNull(result);
        verify(mapper).selectById(1L);
    }
}
```

**集成测试模板**:
```java
@SpringBootTest
@AutoConfigureMockMvc
@ActiveProfiles("test")
class XxxControllerIntegrationTest {
    @Autowired
    private MockMvc mockMvc;
    
    @Autowired
    private ObjectMapper objectMapper;
    
    @Test
    @DisplayName("测试描述")
    void testXxx() throws Exception {
        mockMvc.perform(get("/api/xxx")
                .header("Authorization", "Bearer token"))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.code").value(200));
    }
}
```
