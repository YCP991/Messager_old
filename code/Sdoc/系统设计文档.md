## 1. 项目概述

麦思哲(MaiSiZhe)是一款面向校园场景的即时通讯系统，集成了AI助手功能，支持班级群、课程群等特定场景的即时通讯需求。

### 1.1 主要功能

- 用户注册与登录（JWT认证）
- 群组创建与管理（普通群、班级群、课程群）
- 群聊消息发送与接收
- AI助手自动回复与摘要生成
- WebSocket实时通信

#### 3.1.1 登录页面 (Login.vue)

**功能流程**：

```
用户输入 → 表单验证 → 调用登录API → 保存Token和用户信息 → 跳转聊天页
```

**核心代码逻辑**：

```typescript
// 登录表单数据
const formData = ref({
  username: '',
  password: ''
});

// 表单验证规则
const rules: FormRules = {
  username: {
    required: true,
    message: '请输入用户名',
    trigger: 'blur'
  },
  password: {
    required: true,
    message: '请输入密码',
    trigger: 'blur'
  }
};

// 登录处理函数
async function handleLogin() {
  // 1. 表单验证
  await formRef.value?.validate();
  
  // 2. 调用登录API
  const response = await login({
    username: formData.value.username,
    password: formData.value.password
  });
  
  // 3. 保存Token和用户信息到Store
  userStore.setToken(response.token, response.userInfo);
  
  // 4. 跳转聊天页
  router.push('/');
}
```

```java
@RestController
```

#### 3.3.2 登录服务实现 (UserServiceImpl.login)

```java
@Override
public LoginVO login(LoginDTO dto) {
    // 1. 查询用户
    User user = userMapper.selectOne(
        new LambdaQueryWrapper<User>()
            .eq(User::getUsername, dto.getUsername())
    );
    
    // 2. 验证用户存在
    if (user == null) {
        throw new BusinessException("用户名或密码错误");
    }
    
    // 3. 验证密码
    if (!passwordEncoder.matches(dto.getPassword(), user.getPassword())) {
        throw new BusinessException("用户名或密码错误");
    }
    
    // 4. 检查账号状态
    if (user.getStatus() == 0) {
        throw new BusinessException("账号已被禁用");
    }
    
    // 5. 更新最后登录时间
    user.setLastLoginTime(LocalDateTime.now());
    userMapper.updateById(user);
    
    // 6. 生成JWT Token
    String token = jwtUtil.generateToken(
        user.getId(), 
        user.getUsername(), 
        user.getRole()
    );
    
    // 7. 构建响应
    LoginVO loginVO = new LoginVO();
    loginVO.setToken(token);
    
    LoginVO.UserInfo userInfo = new LoginVO.UserInfo();
    BeanUtils.copyProperties(user, userInfo);
    userInfo.setClassName(user.getClassNo());
    loginVO.setUserInfo(userInfo);
    
    return loginVO;
}
```

#### 3.3.3 JWT认证流程

```
┌─────────────────────────────────────────────────────────────┐
│                      JWT认证流程                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 登录成功 → JwtUtil.generateToken()                      │
│     ├── 传入参数：userId, username, role                     │
│     ├── 生成Claims：{"userId", "username", "role"}          │
│     ├── 设置过期时间：24小时                                  │
│     └── 返回Token字符串                                      │
│                                                             │
│  2. 请求认证 → JwtAuthenticationFilter                       │
│     ├── 拦截所有请求                                         │
│     ├── 从Header提取Token：Authorization: Bearer xxx         │
│     ├── 验证Token：JwtUtil.validateToken()                   │
│     ├── 解析用户信息：JwtUtil.getUserIdFromToken()           │
│     └── 设置SecurityContext                                 │
│                                                             │
│  3. Token解析 → JwtUtil                                     │
│     ├── 验证签名                                             │
│     ├── 检查过期时间                                         │
│     └── 提取Claims中的用户信息                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 4.1.1 群组列表加载 (Chat.vue)

**功能流程**：

```
组件挂载 → 调用API获取群组列表 → 保存到本地状态 → 自动选择第一个群组 → 初始化WebSocket
```

**核心代码逻辑**：

```typescript
// 群组列表数据
const groups = ref<GroupInfo[]>([]);
const currentGroupId = ref<number | null>(null);

// 当前群组信息（计算属性）
const currentGroupName = computed(() => {
  const group = groups.value.find(g => g.id === currentGroupId.value);
  return group?.groupName || '';
});

const currentGroupType = computed(() => {
  const group = groups.value.find(g => g.id === currentGroupId.value);
  return group?.groupType || 0;
});

// 加载群组列表
async function loadGroups() {
  try {
    // 调用API获取当前用户的群组列表
    groups.value = await getUserGroups(userStore.userId);
    
    // 自动选择第一个群组
    if (groups.value.length > 0) {
      selectGroup(groups.value[0]);
    }
  } catch (error) {
    console.error('加载群组失败:', error);
    message.error('加载群组失败');
  }
}

// 选择群组
function selectGroup(group: GroupInfo) {
  currentGroupId.value = group.id;
  // 加载该群组的消息历史
  loadMessages(group.id);
}

// 组件挂载时加载
onMounted(async () => {
  await loadGroups();
  initWebSocket();
});
```

```java
public void joinGroup(Long groupId, Long userId) {
    // 1. 查询群组
    Group group = groupMapper.selectById(groupId);
    if (group == null) {
        throw new BusinessException("群组不存在");
    }
    
    // 2. 检查是否已是成员
    GroupMember existingMember = groupMemberMapper.selectOne(
        new LambdaQueryWrapper<GroupMember>()
            .eq(GroupMember::getGroupId, groupId)
            .eq(GroupMember::getUserId, userId)
    );
    
    if (existingMember != null) {
        if (existingMember.getQuitTime() == null) {
            throw new BusinessException("已是群成员");
        }
        // 重新激活
        existingMember.setQuitTime(null);
        existingMember.setJoinTime(LocalDateTime.now());
        groupMemberMapper.updateById(existingMember);
    } else {
        // 添加新成员
        GroupMember member = new GroupMember();
        member.setGroupId(groupId);
        member.setUserId(userId);
        member.setRole(MemberRoleEnum.MEMBER.getCode());
        member.setJoinTime(LocalDateTime.now());
        member.setQuitTime(null);
        groupMemberMapper.insert(member);
    }
    
    // 3. 更新群组成员数
    group.setMemberCount(group.getMemberCount() + 1);
    group.setUpdateTime(LocalDateTime.now());
    groupMapper.updateById(group);
}
```

```java
public void quitGroup(Long groupId, Long userId) {
    // 1. 查询成员信息
    GroupMember member = groupMemberMapper.selectOne(
        new LambdaQueryWrapper<GroupMember>()
            .eq(GroupMember::getGroupId, groupId)
            .eq(GroupMember::getUserId, userId)
    );
    
    if (member == null || member.getQuitTime() != null) {
        throw new BusinessException("不是群成员");
    }
    
    // 2. 群主不能退群
    if (member.getRole().equals(MemberRoleEnum.OWNER.getCode())) {
        throw new BusinessException("群主不能退群，请先转让群主身份");
    }
    
    // 3. 标记为已退群（设置quitTime）
    member.setQuitTime(LocalDateTime.now());
    groupMemberMapper.updateById(member);
    
    // 4. 更新群组成员数
    Group group = groupMapper.selectById(groupId);
    if (group != null && group.getMemberCount() > 0) {
        group.setMemberCount(group.getMemberCount() - 1);
        group.setUpdateTime(LocalDateTime.now());
        groupMapper.updateById(group);
    }
}
```

```java
@Override
public List<MessageVO> getGroupHistory(Long groupId, Integer limit) {
    String chatId = "g_" + groupId;
    
    // 查询最近的limit条消息
    List<Message> messages = messageMapper.selectList(
        new LambdaQueryWrapper<Message>()
            .eq(Message::getChatId, chatId)
            .eq(Message::getIsRecalled, 0)
            .orderByDesc(Message::getSeqId)
            .last("LIMIT " + limit)
    );
    
    // 反转列表，按时间正序排列
    Collections.reverse(messages);
    
    return messages.stream()
        .map(this::convertToVO)
        .collect(Collectors.toList());
}
```

## 7. WebSocket实时通信模块

### 7.1 前端逻辑

#### 7.1.1 WebSocket管理器 (websocket.ts)

**核心功能**：

```typescript
class WebSocketManager {
  private url: string;
  private token: string;
  private ws: WebSocket | null = null;
  private reconnectCount: number = 0;
  private maxReconnectCount: number = 10;
  private reconnectDelay: number = 3000;
  private heartbeatInterval: number = 30000;
  
  // 连接WebSocket
  connect(): Promise<void> {
    return new Promise((resolve, reject) => {
      // 使用路径参数方式传递token
      this.ws = new WebSocket(`${this.url}/${this.token}`);
      
      this.ws.onopen = () => {
        this.isConnected = true;
        this.startHeartbeat();
        this.flushMessageQueue();
        resolve();
      };
      
      this.ws.onclose = () => {
        this.isConnected = false;
        this.attemptReconnect();
      };
    });
  }
  
  // 发送消息
  send(message: WSMessage): void {
    if (this.isConnected && this.ws?.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify(message));
    } else {
      // 未连接时加入队列
      this.messageQueue.push(message);
    }
  }
  
  // 启动心跳
  private startHeartbeat(): void {
    this.heartbeatTimer = window.setInterval(() => {
      this.send({ type: 'HEARTBEAT' });
    }, this.heartbeatInterval);
  }
  
  // 自动重连（指数退避）
  private attemptReconnect(): void {
    if (this.reconnectCount >= this.maxReconnectCount) {
      return;
    }
    
    const delay = this.reconnectDelay * Math.pow(2, this.reconnectCount);
    this.reconnectTimer = window.setTimeout(() => {
      this.reconnectCount++;
      this.connect();
    }, delay);
  }
}
```

### 7.3 后端逻辑

#### 7.3.1 WebSocket处理器 (WebSocketHandler)

```java
@ServerEndpoint("/ws/{token}")
public class WebSocketHandler {
    
    private static ApplicationContext applicationContext;
    
    @OnOpen
    public void onOpen(Session session, @PathParam("token") String token) {
        // 1. 验证JWT Token
        JwtUtil jwtUtil = getJwtUtil();
        if (!jwtUtil.validateToken(token)) {
            session.close(new CloseReason(CloseReason.CloseCodes.VIOLATED_POLICY, "Token无效"));
            return;
        }
        
        // 2. 获取用户ID
        Long userId = jwtUtil.getUserIdFromToken(token);
        
        // 3. 保存用户会话
        UserSessionManager sessionManager = getSessionManager();
        sessionManager.addSession(userId, session);
        
        // 4. 发送欢迎消息
        sendTextMessage(session, "{\"type\":\"SYSTEM_NOTIFICATION\",\"data\":\"连接成功\"}");
    }
    
    @OnMessage
    public void onMessage(String message, Session session) {
        // 解析消息
        WSMessage wsMessage = objectMapper.readValue(message, WSMessage.class);
        
        // 根据类型处理
        switch (wsMessage.getType()) {
            case "HEARTBEAT":
                handleHeartbeat(userId, session);
                break;
            case "GROUP_MESSAGE":
                handleGroupMessage(userId, wsMessage);
                break;
        }
    }
    
    @OnClose
    public void onClose(Session session) {
        // 移除用户会话
        sessionManager.removeSession(userId);
    }
}
```

#### 7.3.2 会话管理器 (UserSessionManager)

```java
@Component
public class UserSessionManager {
    
    private final ConcurrentHashMap<Long, Session> userSessions = new ConcurrentHashMap<>();
    
    // 添加用户会话
    public void addSession(Long userId, Session session) {
        userSessions.put(userId, session);
    }
    
    // 移除用户会话
    public void removeSession(Long userId) {
        userSessions.remove(userId);
    }
    
    // 获取用户会话
    public Session getSession(Long userId) {
        return userSessions.get(userId);
    }
    
    // 检查用户是否在线
    public boolean isOnline(Long userId) {
        return userSessions.containsKey(userId);
    }
    
    // 获取在线人数
    public int getOnlineCount() {
        return userSessions.size();
    }
}
```
